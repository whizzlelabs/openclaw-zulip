# Manual deployment E2E suite

`npm run test:e2e` runs Vitest against an already deployed OpenClaw plugin and a real Zulip organization. The driver uses Zulip's REST API directly, with a separate test sender, so it does not share the plugin's client implementation. The tests send three messages to unique topics and check replies from the configured OpenClaw user in the corresponding topics. They leave test messages in Zulip for diagnosis.

Set `E2E_ZULIP_URL`, `E2E_SENDER_EMAIL`, `E2E_SENDER_API_KEY`, `E2E_BOT_NAME`, and `E2E_STREAM`. `E2E_REPLY_TIMEOUT_MS` is optional (default 120000). For a private CA, set Node's `NODE_EXTRA_CA_CERTS` to its certificate path before starting npm. Keep these values outside the repository and test logs. Missing configuration fails the suite; tests never silently skip. Vitest can print its working directory, so do not publish raw output from a private host; future public CI should run under a generic path or sanitize the reporter output.

This suite verifies delivery and topic routing, not model output quality. Run it only against a dedicated test organization. It does not install or choose a plugin build; record the installed plugin and OpenClaw versions alongside the result. Keep operator-specific host instructions outside this public repository. Future CI can execute the same `npm run test:e2e` command after installing the exact package artifact into an isolated environment.
