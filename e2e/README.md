# Manual deployment E2E suite

`npm run test:e2e` runs Vitest against an already deployed OpenClaw plugin and a real Zulip organization. The driver uses Zulip's REST API directly, with a separate test sender, so it does not share the plugin's client implementation. Each run checks a topic reply, isolation between two topics, a direct reply carrying a unique prompt marker, and the acknowledgement reaction sequence (start added, start removed, success added) on a topic message. A separate fixture checks failed outbound delivery: the sender can post in its channel, but the configured agent cannot. It must produce no reply and change the acknowledgement from start to error. The suite sends five topic messages and one DM per run. It leaves test messages and terminal reactions in Zulip for diagnosis.

Set `E2E_ZULIP_URL`, `E2E_SENDER_EMAIL`, `E2E_SENDER_API_KEY`, `E2E_BOT_NAME`, `E2E_STREAM`, `E2E_ACK_START`, `E2E_ACK_SUCCESS`, `E2E_ACK_ERROR`, `E2E_FAILURE_AGENT_NAME`, and `E2E_FAILURE_STREAM`. The deployed plugin must have section-level acknowledgement reactions enabled with those emoji names; the sender must be able to receive reaction events for its messages. The failure channel must let the sender post while denying the failure agent permission to post, and no other configured agent should process that channel. The same failure fixture may be used when the success tests target different accounts. `E2E_REPLY_TIMEOUT_MS` is optional (default 120000). For a private CA, set Node's `NODE_EXTRA_CA_CERTS` to its certificate path before starting npm. Keep credentials outside the repository and test logs. Missing configuration fails the suite; tests never silently skip. Vitest may print the test VM's working directory; its output may be shared after checking for credentials and details of unrelated infrastructure.

The unique marker verifies that the DM content reaches the model and returns in its answer; it is not a general assessment of model quality. The failure fixture covers a Zulip delivery error, not a model/provider error that OpenClaw may turn into a delivered error message. Run it only against a dedicated test organization. It does not install or choose a plugin build; record the installed plugin and OpenClaw versions alongside the result. Keep surrounding infrastructure and access instructions in operator-specific documentation. Future CI can execute the same `npm run test:e2e` command after installing the exact package artifact into an isolated environment.
